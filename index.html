APIキーの取得方法
  1. Google Cloud Console（console.cloud.google.com）でプロジェクトを作成
  2. 「APIとサービス」→「ライブラリ」→「YouTube Data API v3」を有効化
  3. 「認証情報」→「認証情報を作成」→「APIキー」を作成し、上の欄に貼り付け
  4. 無料枠は1日10,000ユニット。検索1ページ（50件）あたり約100ユニット消費
